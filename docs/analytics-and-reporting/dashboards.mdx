# Apply filters and save custom views

- Navigate to Analytics and choose the dashboard that aligns with your analytical needs.
- Apply filters available in the top bar.
- Click My Views and save the current filter state.
- You can set a saved view as the default for the dashboard. When you reopen the dashboard, the default saved view will automatically be applied. You can change the default to another saved view or remove the default at any time.

# Drill down or into a visualisation

Interact with the visualisations with the click of a mouse. Drills link elements in the visualisations to other visualisations, letting you browse your data seamlessly.

## Drill down

Drill down opens the same visualisation in a new dialog displaying it broken down to child attributes, e.g. week - day - hour - minute, or region - country.

- Navigate to Analytics and choose the dashboard that aligns with your analytical needs.
- Click on a data point on a visualisation which you want to drill-down.
- Select from the available drill down options.

## Drill into

Drill into visualisations opens a visualisation in a new dialog. This visualisation may contain the same metric as the original one, but it can slice that metric with a new attribute, while filtering for the attribute value selected in the original visualisation.

- Navigate to Analytics and choose the dashboard that aligns with your analytical needs.
- Click on a data point on a visualisation in which you want to drill.
- Select from the available drill into options.

# Export data

## Export individual visualisation data as XLSX or CSV

- Navigate to Analytics and choose the dashboard that aligns with your analytical needs.
- Hover your mouse over the visualisation that you want to export.
- Click the three dots in the top right corner.
- Click Export to XLSX or Export to CSV.
- Save the file.
