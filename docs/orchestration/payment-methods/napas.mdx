## Introduction
Napas uses a **redirect-based payment flow**. When a customer selects Napas at checkout, they are redirected to their bank's authentication interface to confirm the payment, then redirected back to your website or app upon completion. Napas is a single-use payment method where customers must authenticate each payment.

This guide explains the process of integrating Napas into your app or website using Payrails.

## Pre-requisites

Before you start accepting Napas payments with Payrails, there are a few requirements you must meet:

1. Integrate with Payrails using one of our [SDKs](/docs/orchestration/checkout-sdks/index) or our [API](/docs/orchestration/checkout-sdks/accept-payments-via-api)
2. Configure a new [integration account](/docs/orchestration/integrations/index) for Napas via **dLocal** as a Payment Service Provider. If you do not have a dLocal integration already configured in your workspace, please follow the [dLocal integration setup guide](/docs/orchestration/integrations/dlocal) first.
3. Enable Napas as a payment method in your dLocal integration configuration. In the Payrails portal, navigate to **Settings → Integrations**, select your dLocal integration instance, and enable the **Napas** checkbox under Payment methods, then save the account.
4. Enable Napas as a [payment option](set-up-payment-methods) in your workflow.
5. Make sure you're sending the Napas-specific meta fields in your requests.

## Ways to integrate Napas

### Payrails SDK

The simplest way to use Napas with Payrails is to use our [drop-in](/docs/orchestration/checkout-sdks/web/drop-in) in your checkout flow. With this integration type, no additional work is required to accept payments with Napas except for handling success/failure screens for your users.

For a more flexible implementation using our SDK, you can use our `genericRedirectButton` element. See special instructions [here](/docs/orchestration/checkout-sdks/web/elements#generic-redirect-element) for your client-side implementation.

### Server-to-server integration

You can integrate Napas by completely managing your own client-side implementation, and using Payrails APIs with a server-to-server integration to process Napas payments.

#### Parse Napas from lookup response

With a server-to-server integration, you can call our [lookup payment options](/docs/orchestration/payment-acceptance/lookup-payment-options) endpoint to get available payment options. As shown in the example below, you can see `napas` returned as an option of the `paymentCompositionOptions`.

```json
{
  "name": "lookup",
  "actionId": "0bb6413e-cabb-4074-99e6-9e815c69f25b",
  "executedAt": "2026-03-26T12:00:00.000000000Z",
  "data": {
    "paymentCompositionOptions": [
      {
        "integrationType": "redirect",
        "paymentMethodCode": "napas",
        "description": "Napas"
      }
    ]
  },
  "links": {
    "execution": "https://api.payrails.io/merchant/workflows/payment-acceptance/executions/83c534ac-13b7-43e6-b04b-f3e8b4eb4424",
    "authorize": {
      "method": "POST",
      "href": "https://api.payrails.io/merchant/workflows/payment-acceptance/executions/83c534ac-13b7-43e6-b04b-f3e8b4eb4424/authorize"
    }
  }
}
```

#### Pass Napas payment method in request to authorize payment with Payrails

You can then make a request to our [authorize a payment endpoint](/reference/authorizeaction) with `napas` as the `paymentMethodCode`. See an example below:

```json
{
  "executionId": "c0fd1c51-e709-47e5-bfd1-5d1c98f7d990",
  "amount": {
    "value": "700000",
    "currency": "VND"
  },
  "paymentComposition": [
    {
      "integrationType": "redirect",
      "paymentMethodCode": "napas",
      "amount": {
        "value": "700000",
        "currency": "VND"
      }
    }
  ],
  "meta": {
    "customer": {
      "name": "Nguyen Van A",
      "email": "nguyen.vana@email.com",
      "country": {
        "code": "VN"
      }
    }
  },
  "returnInfo": {
    "success": "https://mysuccessurl.com",
    "error": "https://myerrorurl.com"
  }
}
```

> **Note on amounts:** VND uses 2 decimal places but is typically quoted as whole numbers. Amounts should be provided in the smallest currency unit — e.g., `700000` for ₫7,000.
>
>
> **Note:** Napas is a redirect-based, single-use payment method. After calling the authorize endpoint, the customer will be redirected to their bank's authentication interface to confirm the payment. Once confirmed, the customer will be redirected back to the `returnInfo.success` URL. Make sure to provide valid `returnInfo` URLs in your authorization request.

#### Handle the redirect response

After the customer completes the payment, they will be redirected back to your `success` or `error` URL. You should then verify the payment status by checking the workflow execution status via the Payrails API or by listening to webhook notifications.

Napas via dLocal supports the following presentment currency:

* VND — Vietnamese Dong
