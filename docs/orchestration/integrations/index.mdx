# Connect your providers to Payrails

> ℹ️
>
> To accept payments with Payrails, you must connect at least one payment service provider (PSP). You can create and configure a provider integration in the Payrails Portal by following the setup guides below.

Each setup guide walks you through how to configure a payment provider integration in Payrails. It includes:

- Required prerequisites
- Step-by-step instructions to create and configure the integration
- Provider-specific credentials and webhook setup

Use these guides when adding a new payment provider or reviewing an existing setup.

---
