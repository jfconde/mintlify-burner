<Note>
  
**Who should use this guide**

This guide is intended for merchants who:

- Use **Payrails** as a payment orchestrator
- Use **Adyen Payments**
- Are approved to process **raw card data** (PCI DSS compliant)

_Your Adyen account must be approved for raw card data processing. If this is not enabled, payments will fail in production. Request access from Adyen before continuing._

</Note>

<Accordion title="How to request access to raw card data processing">
  1. Email **[support@adyen.com](mailto:support@adyen.com)** and copy
  **[pcisupport@adyen.com](mailto:pcisupport@adyen.com)**. 2. Optionally copy
  Payrails Support to assist with the request. 3. In your request, confirm that
  **Payrails will act as the payment orchestrator and handle card data
  processing**. 4. Include: * The **WS user** associated with your Adyen account
  * The **Payrails PCI compliance document**
</Accordion>

## Create an Adyen integration in Payrails

1. Log in to the **Payrails** portal.
2. Go to **Settings** → **Integrations**.
3. Select **New integration**, then choose **Adyen Payments**.

The Stripe integration setup page appears, showing the required configuration steps.

## Step 1: Name the integration and assign Workspaces

1. Select **Set up** on the **Name and Workspaces** card.
2. Enter a unique, descriptive integration name.
   - **Merchant or brand + provider:** `stellartech-adyen`, `hotelspider-adyen`
   - **Use case or scope:** `adyen-eu-high-risk`, `checkout-uk`
3. Select the Workspaces where this integration applies.
4. Return to the integration overview. Your changes are saved automatically.

### HMAC key (webhook signing key)

<Tip>
  Payrails uses Adyen webhooks to receive asynchronous payment status updates.
</Tip>

<Warning>
  Create the webhook in the same environment (test or live) as your Payrails
  integration.
</Warning>

**In Payrails**

- Copy the **Notification URL** from the **Webhook** section.

<Image
  align="center"
  border={false}
  width="500px"
  src="https://files.readme.io/80622f35609fb5a5c5347d07dcf44f58e14f11ac267301dd744b60c99ea09611-Webhook.png"
/>

**In Adyen**

1. Go to **Developers** → **Webhooks**.
2. Create a new webhook and add the **Standard webhook** option.
3. In **General**, select only the merchant account you are configuring  
   (do not select **All** or the company account).

<Image
  align="center"
  border={true}
  src="https://files.readme.io/ba57e6204447647d2f74fdc3b033954fa63470aa9465cad85f9edb52bb5ac467-Standard_webhook_config.png"
  className="border"
/>

4. In **Server configuration**, paste the Payrails notification URL into the **URL** field.

<Image
  align="center"
  border={false}
  width="600px"
  src="https://files.readme.io/eff8f238ef146b13ef4d8f4a5c0b1f24266c16d7f932d70c96576b68a4939797-Server_configuration.png"
/>

5. In **Security**, generate a new **HMAC key** and copy it.

<Image
  align="center"
  border={true}
  src="https://files.readme.io/7fd9ec827e31de587cffc3c7a5460e2b91036b483cae66aea3a4567f2c69295d-HMAC.png"

/>

6. In **Events**, select all events.
7. In **Additional settings**, select all checkboxes.
8. Save the webhook configuration.

**In Payrails**

- Paste the HMAC key into the **HMAC key** field.

## Step 3: Select payment methods

**In Payrails**

1. Select **Set up** on the **Payment methods** step.
2. Select at least one payment method from the list.
3. Return to the integration overview. Changes are saved automatically.
